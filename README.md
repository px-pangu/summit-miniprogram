# 2026 青年科创峰会 · 活动报名小程序

面向「顶尖高校本科生与研究生」的行业峰会报名小程序，基于**微信原生小程序 + 微信云开发**（云数据库 + 云存储）。

## 功能总览

| 模块 | 说明 |
| --- | --- |
| 活动首页 | 峰会品牌区、活动数据统计、搜索、状态筛选（报名中/进行中/已结束）、活动卡片（名额进度条） |
| 活动详情 | 主视觉大图、基础信息、活动亮点、议程时间轴、特邀嘉宾、报名须知、底部「立即报名」栏 |
| 在线报名 | 姓名/手机/学校/学院专业/学历/参会方向/邮箱/住宿/备注，完整前端校验，提交后生成报名编号 + 签到码 |
| 报名记录 | 状态筛选（待审核/已通过/已取消）、签到码展示、取消报名（事务回退名额） |
| 我的 | 微信授权登录（头像昵称填写能力）、编辑昵称与学校、菜单入口 |
| 活动图片管理 | 创建活动 + 封面上传微信云存储，发布后直达详情页 |

- **登录方式**：微信授权登录（静默换取 openid；头像/昵称使用官方 `chooseAvatar` + `type="nickname"` 合规方案）
- **数据存储**：云数据库 `activities` / `registrations` / `users` 三个集合
- **图片存储**：活动封面、用户头像均上传至微信云存储，前端直接用 `fileID` 渲染
- **并发安全**：报名提交与取消使用云数据库**事务**，保证名额准确

## 快速开始（5 步）

1. **导入项目**：微信开发者工具 → 导入 → 选择本目录，AppID 填自己的（或先用「测试号」，`project.config.json` 中替换 `appid`）。
2. **开通云开发**：工具栏「云开发」→ 开通 → 记住环境 ID（代码使用 `DYNAMIC_CURRENT_ENV`，无需手改）。
3. **建集合**：云开发控制台 → 数据库 → 依次创建 `activities`、`registrations`、`users` 三个集合，权限设置见 `docs/database.md`。
4. **部署云函数**：分别右键 `cloudfunctions` 下 4 个目录 →「上传并部署：云端安装依赖」。再右键 `admin` →「云端运行」，输入 `{ "action": "initDemo" }` 写入 4 条示例活动。
5. **编译运行**：首页即可看到示例活动，走通「报名 → 记录 → 取消」全流程。

## 自定义活动名称

全局文案集中在 `miniprogram/config.js`：活动名称、副口号、主办方、时间地点、参会方向选项。改这一个文件即可整体换皮。

## 设计说明

- 主色 `#2456E8`（商务蓝）+ 深蓝渐变品牌区，浅灰 `#F4F6FA` 底、白色圆角卡片，层级清晰、布局紧凑
- 全部图标为自绘 24 网格线性风格（统一 1.9 描边、圆头端点），由 `tools/gen_icons.py` 程序化生成，不含 Emoji
- 状态语义色：蓝=报名中、琥珀=待审核/已满、绿=已通过/进行中、红=取消/错误
